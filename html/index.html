Architecture
🌐
AWS VPC
Virtual Private Cloud
Isolated private network with public subnet, internet gateway, and custom route tables for controlled traffic flow.
CIDR: 10.0.0.0/16 · us-east-2a
🖥️
AWS EC2
Compute Instance
t3.micro server running Amazon Linux 2 inside the VPC, serving this very webpage you are reading right now.
t3.micro · Amazon Linux 2 · Free Tier
🪣
AWS S3
Private Storage Bucket
Logging bucket with all public access blocked via bucket policy — security best practice enforced through Terraform.
Public Access: Blocked · Encrypted
🔒
AWS IAM
Least-Privilege Roles
IAM user scoped to only EC2, S3, VPC, and CloudWatch. No root credentials used anywhere in this project.
4 Policies · Principle of Least Privilege
📊
AWS CloudWatch
Monitoring and Alerting
CPU utilization alarm triggers when usage exceeds 80% for 4 consecutive minutes — automated observability.
Threshold: 80% CPU · Period: 120s
🛡️
Security Groups
Firewall Rules
Restrictive inbound rules — only ports 80 and 22 allowed. All other inbound traffic blocked by default.
Port 80 + 22 Inbound · All Outbound
